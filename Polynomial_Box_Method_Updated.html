👨‍🏫 I DO — Watch the box fill up

Divide: (2x² + 7x + 3) ÷ (x + 3)

  1. Draw two rows because the divisor has two terms: x and 3.
  2. Ask: x × what = 2x²? Write 2x above the first column.
  3. Multiply down: x(2x) = 2x² and 3(2x) = 6x.
  4. We need 7x total, so 1x remains. Ask: x × what = x? Write 1 above the second column.
  5. Multiply down: x(1) = x and 3(1) = 3. The four cells add to the original dividend.

🧠 Bonus Challenge — Missing terms

When a polynomial skips a power, put a 0 placeholder in the dividend. For example, x³ + 0x² − 4x + 0.

Challenge: (x³ − 4x) ÷ x. This one uses a one-row box, with the divisor x on the left.
